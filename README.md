# BRIO VISUALS (LEGACY)

**⚠️ DEPRECATED**: This project has been superseded by `BRIO_VISUALS_ELECTRON`.

This was the initial Python/Pygame prototype for Brio's visual engine. It implemented:
- Verlet Physics integration.
- Pygame-based windowing.
- Basic sprite rendering.

## Status
Archived. Use the Electron version for "Blender-like" mesh deformation capabilities.
